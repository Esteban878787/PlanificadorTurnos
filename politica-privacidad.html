2. Datos que podemos recopilar

Podemos recopilar los siguientes datos personales cuando utilizas nuestra web:

  • Nombre y apellidos.
  • Dirección de correo electrónico.
  • Información enviada mediante formularios de contacto.
  • Datos necesarios para crear y gestionar una cuenta de usuario.
  • Información técnica como dirección IP, navegador utilizado o datos de navegación mediante cookies.

No recopilamos más información personal de la necesaria para prestar nuestros servicios.

3. Finalidad del uso de los datos

Los datos recopilados pueden utilizarse para:

  • Gestionar solicitudes de contacto o información.
  • Crear y administrar cuentas de usuario.
  • Proporcionar y mejorar nuestros servicios.
  • Mantener la seguridad de la plataforma.
  • Enviar comunicaciones relacionadas con nuestros servicios cuando el usuario lo haya autorizado.

4. Base legal para el tratamiento

El tratamiento de los datos personales se realiza según las siguientes bases legales:

  • El consentimiento del usuario.
  • La ejecución de un servicio solicitado por el usuario.
  • El cumplimiento de obligaciones legales.
  • El interés legítimo en mejorar y proteger nuestros servicios.

5. Servicios de terceros

Para el funcionamiento de esta web podemos utilizar proveedores externos que pueden tratar determinados datos en nuestro nombre.

Entre ellos podemos utilizar servicios como:

  • Supabase, utilizado para servicios de base de datos, autenticación y almacenamiento de información.
  • Otros proveedores tecnológicos necesarios para el funcionamiento de la web.

Estos proveedores aplican sus propias medidas de seguridad y obligaciones de protección de datos.

6. Conservación de los datos

Los datos personales se conservarán durante el tiempo necesario para cumplir la finalidad para la que fueron recogidos y mientras exista una relación con el usuario.

Cuando ya no sean necesarios, se eliminarán o se conservarán bloqueados únicamente durante los plazos legalmente establecidos.

  • Oponerse al tratamiento de sus datos.
